Starter files for New Repository.

- `gitignore/`: from https://github.com/github/gitignore (CC0-1.0). `macOS.gitignore` keeps only
  the General and Resource forks sections of `Global/macOS.gitignore`.
- `license/`: license texts from https://github.com/github/choosealicense.com (`_licenses/`),
  without their front matter. `[year]` and `[fullname]` are filled in when the file is written.
